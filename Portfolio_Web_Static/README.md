# Portfolio Web - Kevin Henkes

Portfolio statique bilingue en HTML, CSS et JavaScript, sans dépendance externe.

## Ouvrir localement

Ouvrir `index.html` dans un navigateur ou servir le dossier avec un serveur HTTP local.

## Pages

- `index.html` : accueil et sélection des projets
- `projets.html` : vue d’ensemble des cinq projets
- `projet-bottleneck.html`, `projet-power-bi.html`, `projet-immobilier.html`, `projet-uoi-games.html`, `projet-retail-sql.html` : études de cas approfondies et bilingues
- `a-propos.html` : profil et parcours
- `cv.html` : CV PDF intégré et transcription HTML accessible

## Accessibilité

Le site comprend une navigation clavier, un lien d'évitement, des modes clair/sombre et contraste renforcé, un agrandissement du texte, des alternatives textuelles pour les graphiques et une interface français/anglais.

Les PDF publics situés dans `assets/cv/` ne contiennent ni adresse postale, ni numéro de téléphone, ni adresse e-mail.
