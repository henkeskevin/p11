Un développeur qui questionne les chiffres.A developer who questions the numbers.

Mon parcours relie développement logiciel, automatisation et analyse de données. J’aime les systèmes dont on peut expliquer le fonctionnement, mesurer les erreurs et reproduire les résultats.My background connects software development, automation and data analysis. I value systems whose behavior can be explained, whose errors can be measured and whose results can be reproduced.

Du logiciel à la décisionFrom software to decision-making

J’ai commencé par le développement Java, l’intégration XML, l’automatisation VBA et la maintenance d’API. Cette expérience m’a appris à chercher la cause d’un problème, à préserver la traçabilité et à livrer un comportement vérifiable.I started with Java development, XML integration, VBA automation and API maintenance. That experience taught me to find root causes, preserve traceability and deliver verifiable behavior.

Ma formation de Business Data Analyst a élargi cette logique aux données : SQL pour interroger, Python pour automatiser les traitements, Power BI pour éclairer les décisions et les statistiques pour quantifier l’incertitude.My Business Data Analyst training extended that logic to data: SQL for querying, Python for workflow automation, Power BI for decision support and statistics for quantifying uncertainty.
